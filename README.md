AutoSlide AI System 

An NLP-based educational platform designed to streamline the creation, management, and sharing of academic lecture materials for professors and students.

About the Project

Preparing lecture slides and study materials manually can be a time-consuming process. AutoSlide AI addresses this by allowing professors to upload academic content such as books and documents and using Natural Language Processing (NLP) to automatically extract key topics and generate structured lecture slides.

When professors update the content, changes are automatically synchronized with students. Students can also generate personalized and interactive study materials, including quizzes, flashcards, and multilingual explanations, to support their learning experience.

Key Features

For Professors

* Automated Slide Generation: Upload course materials (PDF, DOCX, PPTX) and generate structured slides using AI.
* Content Management: Select specific topics from uploaded documents to focus on.
* Edit & Sync: Modify generated slides by adding, deleting, or annotating content. Updates are synchronized with shared student copies without requiring students to re-download the files.

For Students

* Personalized Workspace: View shared slides, save personal copies, and add private notes without modifying the original files.
* AI Study Tools: Generate interactive Flashcards and Quizzes based on slide content.
* Multilingual Explanations: Translate and explain slide content in the student’s preferred language using AI.

System Architecture

The system is designed with maintainability and modularity in mind, utilizing:

* Layered Architecture: Separates the system into Presentation, Business Logic, AI, and Database layers.
* MVC Design Pattern (Model-View-Controller): Separates the user interface, application/data logic, and request handling into distinct components.
